About

What I work on

I work on cloud network security — the unglamorous layer where routing, identity, and controls actually meet. I am a practitioner at Check Point Software Technologies Ltd., spending most of my public time on CloudGuard, Azure networking, Terraform, and DevOps automation.

Recent original work includes a single-apply Azure Virtual WAN plus CloudGuard NVA landing zone, and a Python recon helper that fingerprints WAF/CDN/DNS (including CloudGuard WAF). I am still deepening Python, Terraform, Kubernetes, and CloudGuard — and I am interested in collaborating on cloud security.
